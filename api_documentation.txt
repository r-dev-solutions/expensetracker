Personal Finance API - Documentation
====================================

Live API: https://expensetracker-du0i.onrender.com

-----------------------------------------
Expenses Endpoints
-----------------------------------------
Base URL: https://expensetracker-du0i.onrender.com/api/expenses

GET /api/expenses
  - Retrieve all expenses.

POST /api/expenses
  - Create a new expense.
  - Request Body (JSON): { "description": "Lunch", "amount": 12.0 }

PUT /api/expenses/:id
  - Update an existing expense by its ID.
  - Request Body (JSON): Fields to update.

DELETE /api/expenses/:id
  - Delete an expense by its ID.

-----------------------------------------
Monthly Statements (Estado de Resultado Mensual)
-----------------------------------------
Base URL: https://expensetracker-du0i.onrender.com/api/monthly-statements

GET /api/monthly-statements
  - Retrieve all monthly statements.

POST /api/monthly-statements
  - Create a new monthly statement.
  - Request Body (JSON): 
    {
      "month": "2024-06",
      "income": 3000,
      "debt": 1200,
      "notes": "Salary and loan payment"
    }

PUT /api/monthly-statements/:id
  - Update a monthly statement by its ID.

DELETE /api/monthly-statements/:id
  - Delete a monthly statement by its ID.

-----------------------------------------
Payments Calendar/Agenda
-----------------------------------------
Base URL: https://expensetracker-du0i.onrender.com/api/payments

GET /api/payments
  - Retrieve all scheduled payments.

POST /api/payments
  - Create a new payment.
  - Request Body (JSON):
    {
      "description": "Credit Card Bill",
      "amount": 500,
      "dueDate": "2024-06-15",
      "status": "pending"
    }

PUT /api/payments/:id
  - Update a payment by its ID.

DELETE /api/payments/:id
  - Delete a payment by its ID.

-----------------------------------------
Notes:
- All endpoints accept and return JSON.
- All IDs are MongoDB ObjectIds.
- The "date" field in expenses is set automatically if not provided.
- The "dueDate" field in payments must be a valid date string (ISO format recommended).
